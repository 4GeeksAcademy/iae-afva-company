# Memory Management Rules

## Scope

This rule applies by file pattern whenever an agent creates or modifies files under `./memory-bank/**`.

## Project Progress

File: `./memory-bank/progress.md`

Each progress entry must include:

- Date (`YYYY-MM-DD`).
- Summary of changes implemented.
- Next steps, when applicable.

## Technical Decisions

File: `./memory-bank/decisions.md`

Each decision must include:

- Decision ID.
- Date (`YYYY-MM-DD`).
- Context or problem.
- Decision taken.
- Rationale and relevant trade-offs.

## General Rules

- Preserve existing history; do not overwrite previous entries.
- Keep entries concise and factual.
- Do not record assumptions as confirmed decisions.
